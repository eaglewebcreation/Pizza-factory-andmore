# The Pizza Factory & More

Static website for The Pizza Factory & More, built by Eagle Web Creation.

- `main` is the live branch. Hostinger deploys it automatically on every push.
- `staging` is for previewing changes before they go to `main`.
- Online ordering buttons switch on when `ORDER_URL` in `site.js` is set.
- Canonical, Open Graph and sitemap addresses use the planned domain, thepizzafactoryandmore.com.
